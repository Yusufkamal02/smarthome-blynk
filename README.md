This is SmartHome prototype project for Educational KiT
Before Start to pull this repository you need to prepare this component's bellow:
1. ESP32 Devout V1
2. Expansion Board/Breadboard
3. LCD I2C 16x2 LiquidCrystal
4. Sensor Magnet Reed Switch
5. Sensor Gas MQ-2
6. Sensor DHT22 Temperature & Humidity
7. LED 4 5mm mix color, 1 for Nightlight
8. Buzzer
9. Mini fan DC
10. Mini Driver Motor
11. Jumper Wire M-M, M-F, F-F
12. Cable Uploader

Makesure all these components available and happy learn!
